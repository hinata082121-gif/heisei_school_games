# サイト構成

## 目的

平成学校ゲームズ公式サイトは、ゲーム本体を置く場所ではなく、シリーズ全体のブランド紹介、ゲーム導線、攻略記事、開発ログ、SNS導線をまとめる公式ポータルです。

## 主要ページ

### /

学校マップ型トップページ。

役割：

- ブランド紹介
- ゲーム導線
- 攻略・ブログ導線
- SNS導線

### /games

ゲーム一覧ページ。

### /games/chime-dash

チャイムダッシュ紹介ページ。

外部ゲームURL：
https://chimedash.vercel.app/

### /games/kyusyoku-okawari

給食おかわり戦争紹介ページ。

外部ゲームURL：
https://kyusyoku-okawari.vercel.app/

### /games/eraser-battle

机上決戦！消しゴム落とし紹介ページ。

外部ゲームURL：
https://keshigomu-battle.vercel.app/

### /guides

攻略・遊び方一覧。

### /guides/[slug]

攻略記事詳細。

### /blog

開発ログ・ブログ一覧。

### /blog/[slug]

ブログ記事詳細。

### /social

SNS導線ページ。

### /about

ブランド紹介。

### /contact

問い合わせ案内。

### /privacy

プライバシーポリシー。

### /terms

利用規約。
